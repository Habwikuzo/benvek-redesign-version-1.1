# Visual direction — Refined Version 1.1

- **Brand feel:** clean, confident and technical, with a natural/healthy-air visual tone.
- **Palette:** deep forest green `#123F2D`, darker green `#0B2D20`, leaf green `#2E8B57`, pale neutral `#F5F7F2`, and mint accents.
- **Typography:** editorial serif headings paired with a readable system sans-serif body font.
- **Hero:** dark green field with an image crop taken from the supplied Benvek booklet; clear value proposition and two enquiry/navigation actions.
- **Components:** rounded product cards, restrained borders/shadows, readable technical tables, strong enquiry CTAs.
- **Responsive:** collapsible mobile navigation, fluid headings, stacked cards and tables that scroll horizontally on small screens.
- **Accessibility:** skip link, visible focus states, semantic sections, responsive navigation and reduced-motion support.
- **Content principle:** brochure-supported facts are distinguished from information Benvek still needs to confirm.
